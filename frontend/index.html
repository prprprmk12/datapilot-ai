ПОДКЛЮЧЕНИЕ МОДЕЛИ

Модель за вашими ответами

Для запуска Tiny Aya на CPU через llama.cpp добавьте в .env:

MODEL_PROVIDER=model_api
MODEL_BASE_URL=http://model:8080/v1
MODEL_ID=CohereLabs/tiny-aya-global
MODEL_TIMEOUT_SECONDS=180

Затем в папке проекта:

sudo docker compose --profile ai up --build

При первом старте скачивается GGUF-модель (~2,14 ГБ). Нужно принять условия модели на Hugging Face; при запросе доступа задайте HF_TOKEN. Модель работает на CPU, ответы могут занимать несколько минут. Это inference, без fine-tuning.

Настройки применяются на сервере. Ключи не передаются в браузер.
