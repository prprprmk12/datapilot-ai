Прогнали неизменённую Tiny Aya Global Q4_K_M на CPU. Взяли по первой задаче из каждого семейства dev. Исходный отчёт содержит результаты до исправления поведения чата при пустой выборке.

| Задание | Эталон | Наблюдение | Время |
|---|---|---|---:|
| Число уникальных покупателей | buyers = 3 | SQL сослался на несуществующий столбец buyers | 217 с |
| Возвраты для заказа 1 | refunded_amount = 0 | Фильтр отклонил синтаксис процедурного IF | 89 с |
| Клиенты без paid-заказов | Sam, id 4 | Условие статуса в WHERE исключило нужную строку. PostgreSQL вернул пустой список, модель перечислила вымышленных клиентов | 187 с |

Строгое совпадение в пилоте 0 из 3. Последний запрос сохранил имена столбцов и провалил сравнение строк. В этом отчёте счётчик инструментов учитывает завершённые вызовы. Новые прогоны сохраняют также имя, аргументы и тип ошибки неудачного вызова.

Три исправления записаны в `data/correction-candidates.jsonl` для ручной проверки. Полный dev содержит 12 задач. Финальные 18 задач test остаются отдельными. GRPO ждёт доступных исходных весов и среды обучения. В текущем Python AgentTune и PyTorch отсутствуют. Проверка NVIDIA не обнаружила доступного драйвера.

Во второй базе загрузили альтернативный seed с новыми клиентами, заказами, товарами и платежами. Все 99 эталонных запросов выполнились с теми же именами столбцов. Результаты изменились у 56 train, 7 dev и 16 test задач. Модель проверялась на исходной базе.

Чат получает статусы через отдельный поток и позволяет закрыть его кнопкой отмены. Сервер проверяет отмену между шагами. Выполняющийся вызов модели может продолжаться до ответа или таймаута. Если SQL вернул пустую выборку, итоговый текст сообщает об этом. Потоковый demo-запрос на выручку проверен в браузере на PostgreSQL. Результат составил 870.
